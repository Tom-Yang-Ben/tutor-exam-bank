### 0.1 代碼原則

- **沒搬的知識點，代碼一律不重編。** 搬走後空出的序號不補位、以後也不再使用：
  - 「科學的態度與方法」剩 .01、.02、.04
  - 「四大基本交互作用」剩 .01、.02、.04、.05、.06
  - 「動量守恆與碰撞」剩 .01、.02、.04、.05、.06
  - 這三章的 `sort` 也保留原值（有跳號），教學順序不受影響。
- 理由：`kc:load` 以 code upsert，而且不會刪除種子檔裡已經沒有的 code。如果把「四大基本交互作用.03」改給強交互作用用，DB 裡原本掛在「電與磁的統一」這一列的老師修改與題目標註，會被默默套到另一個概念上。不重用代碼，舊列最多變成孤兒列，不會指錯內容。
- 因此這 173 條再跑一次 `kc:load` 時是「內容相同」；只有先備被改寫的 3 條會在先備關係上有變動。

### 口語版寫法（第 3.5 條的套用方式）

- 第一句說「這是什麼」，中間講怎麼算、看到什麼題目要想到它，**最後一句放最常見的錯**。少數幾條的最後一句是檢查技巧，例如斜面分力、核反應配平。
- 新寫的 17 條與改寫的 2 條（`PHYS.質心與角動量.03`、`.05`）都對學生說「你」。長度 88–146 字，每條 2–3 句。其餘沿用 v1 的文字，沒有動。
- 比喻只用在結構完全對應的地方，Owner 審定時可以特別看這幾條是否過關：
  - `PHYS.簡諧運動(SHM).02`：簡諧運動＝等速圓周運動在直徑上的投影（「影子」）。這在數學上就是同一件事。
  - `PHYS.剛體轉動與平衡.05`、`PHYS.質心與角動量.05`：轉動慣量「在轉動裡扮演質量的角色」，對應 τ = Iα ↔ F = ma。
  - `PHYS.質心與角動量.04`：質點角動量「跟力矩是力乘力臂同一種算法，只是把力換成動量」。兩者都是參考點到作用線的垂直距離乘上一個向量的大小，是定義上的對應，不是比喻。
  - `PHYS.質心與角動量.03`：「把整個系統當成全部質量集中在質心、只受外力的一個質點」。這是質心運動定律本身的敘述。
  - `PHYS.電場與電位.05`：均勻電場中的運動「跟重力場裡丟東西一樣」，兩者都是固定力造成的等加速度運動。
  - `PHYS.物理光學（干涉繞射）.02`：雙狹縫就像兩個同步的光源。
- 沒有用「拉行李箱」「紅綠燈」這類只是好記的比喻。
