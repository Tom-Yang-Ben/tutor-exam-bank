### 1.1 用到比喻的條目（請依第 3.5 條第 4 點確認）

只在結構精確對應時使用，共 3 處：

| code | 比喻 | 為什麼認為是精確的 |
|---|---|---|
| `CHEM.原子量與莫耳.03` | 莫耳就像一打 | 兩者都是「固定個數的計數單位」，差別只有個數 |
| `CHEM.有機化合物的組成與結構.06` | 鏡像異構物像左手和右手 | 「對掌性」一詞就是由手而來，互為鏡像且不能重疊 |
| `CHEM.先進材料.02` | 奈米碳管就是石墨烯捲成的管子 | 這是結構描述，不是類比 |

另外 `CHEM.碰撞學說與催化.02` 用「爬到峰頂」描述位能圖，屬於圖形描述。

## 2. 最沒把握的 10 條

| # | code | 名稱 | 原因 |
|---|---|---|---|
| 1 | `CHEM.反應速率定律.06` | 反應機構與速率決定步驟 | 不確定 108 選修化學是否仍教反應機構（舊課綱有）；若不在課綱內建議刪除，本章會剩 5 條。另外只講「慢步驟決定速率」，沒處理慢步驟含中間產物的情形。 |
| 2 | `CHEM.氣體性質與理想氣體.04` | 氣體動力論 | 課綱可能只要求定性；口語版寫了「方均根速率與分子量平方根成反比、氫氣是氧氣的 4 倍」，若課本不談方均根速率，要改成「平均速率」的定性說法。 |
| 3 | `CHEM.溶液的依數性質.05` | 電解質溶液的依數性質 | description 寫了弱電解質 i = 1 + α（AB 型）；不確定 108 版本是否要求到弱電解質，可能只要求強電解質乘粒子數。 |
| 4 | `CHEM.原子軌域與電子組態.01` | 氫原子光譜與波耳模型 | 給了 −1312/n² kJ/mol 與三個系列名稱（來曼、巴耳末、帕申）；各版本要求的深度不同，數值請對照課本。 |
| 5 | `CHEM.元素性質的週期性.03` | 游離能 | 兩個例外（Be > B、N > O）我用「硼拿走能量較高的 2p 電子、氧拿走已配對互斥的電子」解釋；不少講義寫成「全滿、半滿較穩定」。兩種說法 Owner 擇一。 |
| 6 | `CHEM.氧化數與氧化還原滴定.05` | 常見氧化劑與還原劑的產物 | MnO₄⁻ 只寫了酸性（Mn²⁺）與中性／弱鹼性（MnO₂），省略強鹼性（MnO₄²⁻）；Cr³⁺ 寫「綠色」，實際顏色隨配位環境在綠與紫之間。 |
| 7 | `CHEM.常見的非金屬與金屬.07` | 過渡金屬與錯離子 | 不確定錯離子在 108 選修化學的範圍；顏色描述（Fe³⁺ 黃褐、Fe²⁺ 淡綠）為常見說法，依濃度與陰離子會有差異。 |
| 8 | `CHEM.有機化合物的組成與結構.01` | 燃燒分析求實驗式 | 吸收劑各版本不同（過氯酸鎂／無水氯化鈣；氫氧化鈉／鹼石灰），請以學生使用的課本為準。 |
| 9 | `CHEM.溶解度.05` | 沉澱反應與溶解性規則 | 規則的寬嚴各版本不同（例如 PbCl₂、CaSO₄ 算難溶還是微溶）；也不確定這個主題在課本裡是放在「溶解度」還是「化學反應式／水溶液反應」。 |
| 10 | `CHEM.化學反應中的能量變化.04` | 熱化學反應式的倍數與逆寫 | 必修與選修一的界線不確定：若必修已教赫斯定律，這一條與 `CHEM.反應熱與赫斯定律.01` 要重新分配（見第 3 節 A）。 |

## 3. 需要 Owner 決定的章節切法

化學章節表本身是 AI 草擬（第 3.3 條），章名一改，知識點代碼就得跟著遷移，所以以下只調整知識點的歸屬，不動章名。

- **A. 必修「化學反應中的能量變化」與選修一「反應熱與赫斯定律」**：目前必修放吸放熱、熱化學反應式、能量圖、倍數與逆寫、卡計測量；選修一放赫斯定律、生成熱、燃燒熱、鍵能、物態與反應熱。若使用的課本把赫斯定律或生成熱放在必修，請指示搬移。
- **B. 重量莫耳濃度與莫耳分率**：放在選修一「溶液的依數性質」第 01 條，而不是必修「溶液的種類與濃度」。若必修已教，要搬到必修，依數性質那章會剩 5 條。
- **C. pH 的兩處**：必修「酸鹼反應」.03 講 pH 定義與酸鹼性，選修三「酸鹼解離與pH值」.02 講 Kw、pOH 與溫度效應。刻意分開，但兩條內容有部分重疊，Owner 可決定是否合併。
- **D. 電池出現三處**：必修「氧化還原反應」.05（化學電池原理）、必修「能源與先進科技」.03（電池種類，從能源角度）、選修四「電化電池」整章。若覺得必修兩條重複，建議保留「氧化還原反應」.05、把「能源與先進科技」.03 改成別的能源主題。
- **E. 奈米與先進材料**：必修「能源與先進科技」.05 講奈米尺度的特性；選修四「先進材料」講導電高分子、碳材料、超導、液晶、形狀記憶合金與半導體。後者的第 05 條把三種材料合在一條，是因為每種份量都不足以單獨成為一個知識點。
- **F. 速率因素的兩個角度**：選修二「反應速率定律」.02 講現象（哪些因素影響速率），「碰撞學說與催化」.03／.04 用碰撞學說解釋。刻意分開，若嫌重複可刪前者。
- **G. 皂化出現兩處**：必修「生活中的化學」.02（肥皂製造）與選修五「羧酸與酯」.03（酯的鹼性水解）。
- **H. 胺基酸**：放在「胺與醯胺」.04；「聚合物」.05 只把蛋白質當天然聚合物提一句。若課本把胺基酸與蛋白質放在聚合物章，請指示搬移。
- **I. 「常見的非金屬與金屬」7 條**：依元素家族切（鹵素、氧硫、氮磷、碳矽、鹼金屬與鹼土金屬、鋁、過渡金屬與錯離子），是 44 章中最多的一章。課本若以「非金屬／金屬／錯合物」三節切，可能要重新分組。
- **J. 「生活中的化學」5 條**：選了清潔劑、皂化、食品、衣料纖維、藥物。各版本的選材差異大（有的談化妝品、塑膠、材料），請對照課本增刪。
- **K. 「化學基本定律」的順序**：教學順序排成質量守恆 → 定比 → 倍比 → 道耳頓原子說 → 氣體化合體積與亞佛加厥。倍比定律其實是道耳頓由原子說推得的，也有課本把原子說放在倍比之前。

## 4. 跨科先備引用

**種子檔內沒有任何跨科引用。** 其他科的種子檔不在本分支，我無法確認對方第 01、02 條的內容，寧可不寫，也不要指向錯的知識點。

整合時建議補上以下先備（寫進 `kc_prerequisites`，`src = 'curriculum'` 或 `human`），請在 KC-M／KC-P 定稿後逐條核對目標 code：

| 化學知識點 | 建議的先備（他科章節 → 應指向的內容） | 理由 |
|---|---|---|
| `CHEM.酸鹼反應.03`（pH 值） | 數學「指數與對數」→ 對數的定義 | pH 是負的對數 |
| `CHEM.反應速率定律.05`（一級反應與半生期） | 數學「指數與對數」→ 指數函數 | 剩餘量為二分之一的 n 次方 |
| `CHEM.原子軌域與電子組態.01`（波耳模型） | 物理「原子結構與光譜」→ 氫原子光譜或波耳模型 | 兩科同一主題 |
| `CHEM.氣體性質與理想氣體.04`（氣體動力論） | 物理「功與動能」→ 動能的定義 | 平均動能與溫度 |
| `CHEM.電解與電鍍.04`（法拉第電解定律） | 物理「電流與電路」→ 電流與電量 | 電量 = 電流 × 時間 |

## 5. 產出方式與複查

- 以分冊資料檔（先備用「章名／名稱」表示）產生 JSON，名稱解析成 code 時一併檢查重複、長度、句數與 LaTeX 殘留；產生器是一次性工具，**不進版控**，之後以 JSON 本身為準。
- 每寫完一冊就跑一次 `validate_kc_seed.js`，並逐條複查化學內容。最後整份再通讀一次口語版，修正了三處：「官能基與有機物的分類」原本寫「酯基兩邊都接碳鏈」，甲酸酯不成立，改為「羧基上的氫換成烴基就是酯」；「生活中的氧化還原」最後一句改成「別以為只要接觸氧氣就一定會生鏽」；「鹵素及其化合物」重寫氫氟酸那一句。
- 數值抽查：Cl 平均原子量 35.5、Ca(OH)₂ 式量 74、24.5 L（25°C）、Kb 0.52／Kf 1.86、0.1 M 醋酸 pH 約 2.9、鋅銅電池 1.10 V、醋酸滴定當量點約 pH 8.7、Ksp 與 s 的換算（4s³、108s⁵）、C₄H₈O₂ 的酯有 4 種，均已驗算。
